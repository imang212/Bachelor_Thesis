\chapter{Externí přílohy}
\label{app:external}

Zdrojové kódy navrženého systému, instalační a~konfigurační skripty, kontejnerové definice, dokumentace architektury, vyexportované výsledky měření i~samotný text této bakalářské práce jsou uloženy v~přiloženém elektronickém archivu a~verzovány ve veřejném GitHub repozitáři dostupném na adrese: \url{https://github.com/imang212/Bachelor_Thesis}.

Detailní postupy instalace a~konfigurace obou testovaných výpočetních platforem jsou vyčleněny do samostatných adresářů elektronické přílohy a~opírají se o~oficiální dokumentaci výrobců:

\begin{itemize}
    \item \textbf{Konfigurace a~instalace okrajového zařízení (Raspberry Pi~5 + Hailo-8):} Nachází se v~adresáři \texttt{rpi\_src/}. Zahrnuje automatizační skript \texttt{autosetup\_hailo\_rpi5.sh} pro přípravu 64bitového systému Raspberry Pi~\acs{OS} (Debian Bookworm)~\cite{raspberrypi_docs_2024}, aktivaci sběrnice \acs{PCIe} Gen~3, instalaci ovladačů modulu AI HAT+~\cite{raspberrypi_ai_kit}, prostředí HailoRT, knihoven TAPPAS~\cite{tappas_user_guide_331} a~multimediálního frameworku GStreamer~\cite{gstreamer_docs}. Skript \texttt{autorun.sh} následně zajišťuje automatické spouštění detekční pipeline, databázového odběratele a~webového rozhraní po startu systému (doplněné o~manuál v~\texttt{rpi\_src/pipeline/script-guide.md}).
    \item \textbf{Konfigurace a~instalace referenční stanice (PC + NVIDIA \acs{GPU}):} Nachází se v~adresáři \texttt{pc\_src/} (pro inferenci v~prostředí CUDA s~knihovnami Ultralytics~\cite{ultralytics_yolov8_docs}, OpenCV~\cite{bradski_opencv_2000} a~algoritmem ByteTrack~\cite{zhang_bytetrack_2022} dle \texttt{pc\_src/requirements.txt} a~\texttt{pc\_src/docker-compose.yml}) a~v~adresáři \texttt{rpi\_src/model\_compile/} (pro kompilaci a~8bitovou kvantizaci modelů do formátu \acs{HEF} pomocí nástrojů Hailo Dataflow Compiler~\cite{hailo_dfc_docs} a~Hailo Model Zoo~\cite{hailo_model_zoo}).
\end{itemize}
