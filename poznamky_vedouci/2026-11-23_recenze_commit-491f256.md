## NOVÉ PROBLÉMY

### **A) `yolov8m_architecture.png` — 1,65 MB, v git mimo LFS**

V `thesis_text/images/` nový obrázek **1 649 059 B** (1,65 MB) — zapsaný jako
`100644` (git mode), **bez LFS** (`git check-attr` → jen `linguist-documentation`).
Je 4× až 5× velčí než ostatní obrázky (300–800 KB).

**Doporučení:** přidat `thesis_text/images/*.png` soubor s velikostí ≥ 1 MB pod LFS
(`.gitattributes`), nebo zmenšit obrázek (komprimace → ~500 KB). V git historie
by pak nebyl 1,65 MB binár — zbytečná režie pro `git pull` a `git clone`.
