\chapter{Introduction}
The monitoring of road traffic is an essential task for modern urban infrastructure management. This thesis focuses on the development of an automated system using \textbf{Computer Vision} and \textbf{Edge AI} to provide real-time insights into traffic density and object classification.

\section{Project Objectives}
The primary goal of this project is to implement a robust pipeline that:
¨\begin{itemize}
    \item Processes RTSP video streams in real-time.
    \item Detects and classifies vehicles and pedestrians using the \textbf{YOLO} model.
    \item Stores telemetry data in a \textbf{PostgreSQL} database via \textbf{MQTT}.
    \item Visualizes the results on an interactive dashboard.
\end{itemize}



\chapter{System Architecture}
The system follows a modular architecture to ensure low latency and data persistence.

\section{Data Pipeline}
1. \textbf{Ingestion:} RTSP stream processed via GStreamer.
2. \textbf{Inference:} Object detection using a quantized YOLO model.
3. \textbf{Transmission:} Metadata sent via MQTT protocol.
4. \textbf{Storage:} Historical analysis stored in PostgreSQL.

\chapter{Mathematical background}
To evaluate the detection accuracy, we define the Loss function used during the fine-tuning phase:

\begin{equation}
L = \lambda_{coord} \sum_{i=0}^{S^2} \sum_{j=0}^{B} \mathds{1}_{ij}^{obj} \left[ (x_i - \hat{x}_i)^2 + (y_i - \hat{y}_i)^2 \right]
\end{equation}
